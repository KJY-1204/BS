# Spec Delta

## ADDED Requirements

### Requirement: The kind choice shows each kind's trait
The list the boss player chooses a kind from in the waiting room SHALL show, for each kind that has a trait, the trait's name beside the kind's skills.

#### Scenario: Reading the choices
- **WHEN** the boss player looks at the kinds in the waiting room
- **THEN** the giant and the sniper show their trait names and the standard kind shows none
