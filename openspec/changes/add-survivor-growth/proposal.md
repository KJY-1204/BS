# Proposal

## Why

전투 코어(`add-survivor-combat`)까지 생존자는 쏘고 맞고 쓰러지고 살아날 수 있지만, 판이 진행돼도 강해지지 않는다. 뱀서라이크의 핵심인 "몹을 잡아 성장하고 빌드를 고른다"가 없어서 게임이 단조롭다. 캐릭터별 공격과 스킬(Change 5)을 만들기 전에, 캐릭터 구분 없는 임시 데이터로 성장 시스템의 틀(경험치, 레벨, 스탯 상승, 마나, 키 입력 스킬, 레벨업 선택)을 먼저 확정한다. 틀이 정해지면 Change 5는 캐릭터별 데이터와 공격 모양만 채우면 된다.

## What Changes

- **경험치**: 몹을 처치하면 즉시 경험치가 지급된다(보석 없음). 처치 위치에서 일정 거리 안에 있는 살아 있는 생존자 전원이 같은 양을 각자 받는다. 누가 처치했는지는 상관없고, 죽은 생존자와 보스는 받지 않는다.
- **레벨과 스탯**: 생존자마다 개인 레벨이 있고 상한이 있다. 레벨업하면 최대 체력, 최대 마나, 투사체 피해가 자동으로 오르지만(임시 공통 성장표) 현재 체력과 마나는 회복되지 않는다. 레벨은 모두에게 보이고 경험치 진행은 본인만 본다.
- **마나**: 생존자 마나가 시간이 지나면 일정 속도로 회복되고 스킬을 쓰면 줄어든다. 본인만 본다.
- **키 입력 스킬**: 스킬 슬롯 Q와 E가 생기고, 소유자가 키를 누르면 서버가 마나, 쿨타임, 생존 여부, 습득 여부를 판정해 발동한다. 이번에는 캐릭터 구분 없는 임시 스킬 둘이다(범위 폭발, 일시 연사 강화). 발동은 투사체처럼 서버 판정 + 이벤트 복제(클라이언트는 연출만)이고, 전투 이벤트에 스킬 종류를 추가한다.
- **스킬트리와 레벨업 선택**: 스킬을 데이터로 정의하고(패시브/액티브, 최대 랭크, 선행 조건, 효과) 작은 공통 임시 트리를 둔다. 레벨업하면 서버가 선택지 3개를 정해 본인에게만 보여 주고, 숫자 키 1/2/3으로 고른다. 게임은 멈추지 않으며, 제한 시간 안에 고르지 않으면 서버가 선택지 중 하나를 무작위로 자동 선택한다. 연속 레벨업은 차례대로 처리한다.
- **생존자별 전투 수치**: 투사체 피해와 발사 쿨타임, 최대 체력이 생존자마다 달라질 수 있도록 기존 시뮬레이션을 확장한다.
- **화면**: 경험치 막대와 레벨, 마나 막대, 스킬 슬롯과 쿨타임, 레벨업 선택 패널(남은 시간), 캐릭터 위 레벨 표시를 임시 IMGUI로 보여 준다. 스킬 발동 연출도 최소한으로 둔다.
- 방이 끝나면 성장 상태가 모두 초기화된다.
- 범위 밖: 대기방과 캐릭터 선택, 캐릭터별 고유 공격과 스킬/스킬트리(Change 5), 보스 관련 모든 것(Change 6), 에셋, 점수, 사망 시 경험치 손실, 이동 속도 성장.

## Capabilities

### New Capabilities
- `survivor-leveling`: 경험치 지급과 나눔, 레벨과 상한, 자동 스탯 상승(회복 없음), 레벨 표시.
- `survivor-mana-skills`: 마나와 시간 회복, 키 입력 스킬의 서버 판정과 쿨타임, 임시 스킬의 효과와 연출 복제.
- `skill-tree-selection`: 스킬트리 데이터 규칙, 레벨업 선택지, 선택과 시간 초과 자동 선택, 연속 레벨업 큐, 선택 화면.

### Modified Capabilities
- `survivor-health`: 최대 체력이 생존자마다 오를 수 있고, 오를 때 현재 체력은 그대로이며 부활 체력도 그 생존자의 최대 체력을 따른다.
- `aimed-attack`: 투사체 피해와 발사 쿨타임이 생존자별 수치를 따른다.
- `attack-replication`: 스킬 발동 이벤트가 같은 표시 시계로 재생되고, 스킬을 포함해도 전투 트래픽 예산을 지킨다.
- `mob-simulation`: 범위 안의 몹에게 한꺼번에 피해를 주는 기능을 추가한다.

## Impact

- 코드: `Assets/Scripts/Growth/`(경험치/레벨, 스킬트리 데이터, 선택 큐, 마나와 스킬, 스탯 계산, 서버 연결, 화면)를 새로 추가한다. `SurvivorSim`(생존자별 최대 체력), `AttackSim`/`ProjectileSim`(생존자별 피해와 쿨타임), `MobSim`(범위 피해), `CombatCodec`/`CombatServer`/`CombatClient`/`CombatView`(스킬 이벤트), `PlayerCombat`(최대 체력 복제), 플레이어 프리팹과 씬 설정이 바뀐다.
- 네트워크: 새 패키지는 없다. 레벨과 최대 체력은 모두에게, 경험치/마나/스킬 랭크는 소유자에게만 복제하고, 레벨업 선택지와 스킬 결과는 소유자에게만 보내는 RPC로 전달한다.
- 입력: 키 Q, E(스킬)와 1, 2, 3(선택)을 Input System으로 읽는다.
- 테스트: 경험치, 선택 큐, 마나, 스킬, 스탯 계산은 순수 C#이라 EditMode로, 네트워크 동작은 개발 빌드 여러 프로세스 로그와 실제 Relay로 검증한다.
- 이후 change: Change 5가 캐릭터별 성장표, 스킬, 스킬트리 데이터를 이 틀 위에 채우고, Change 6의 보스가 이 레벨 개념과 독립적으로 붙는다.
