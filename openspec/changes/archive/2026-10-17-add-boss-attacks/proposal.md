# Proposal

## Why

보스는 이제 몹을 소환하고 명령을 내리지만, 보스 자신이 생존자에게 줄 수 있는 피해는 몸으로 부딪히는 것뿐이다. 보스가 직접 쏘는 공격이 없어서 생존자는 몹만 상대하면 되고, 보스는 "플레이어다운" 보스전의 중심이 되지 못한다. 보스에게 마우스로 조준해 쏘는 투사체를 주고, 체력이 줄수록 더 위협적이 되게 해서 생존자가 피해야 할 것과 보스가 쫓기며 버티는 긴장을 만든다. 이미 있는 투사체, 공격 시뮬레이션, 전투 이벤트, 생존자 피해 규칙을 재사용해 위험을 낮춘다.

## What Changes

- **보스가 투사체를 쏜다.** 보스 플레이어가 마우스로 조준하고 왼쪽 클릭(패드는 오른쪽 트리거)을 누르고 있으면 서버가 쿨타임마다 보스 위치에서 한 발을 쏜다. 보스는 판이 진행 중이고 쓰러지지 않았을 때만 쏠 수 있다. 보스 투사체는 생존자만 맞히고 몹과 보스 자신은 지나간다. 생존자의 투사체가 생존자를 지나가는 지금 규칙은 그대로다.
- **맞은 생존자는 피해를 입는다.** 투사체 피해는 기존 생존자 피해 규칙(체력 하한 0, 맞은 뒤 잠깐의 보호 시간, 죽음, 부활 보호)을 그대로 따른다. 보호 시간 중이거나 이미 쓰러진 생존자는 맞지 않고 투사체가 지나간다.
- **체력이 줄수록 보스가 강해진다.** 보스의 현재 체력 비율에 따라 발사 간격이 줄고 투사체 피해가 늘어난다(연속적인 비율 계산, 값은 모두 가정값). 가득 찬 체력에서는 기본 값이다. 보스 체력은 서버가 정하고, 강화도 서버 규칙이다.
- **키 배치가 바뀐다.** 왼쪽 클릭은 발사가 되고 소환은 Space 키 하나로 옮긴다. 오른쪽 클릭 목표 지정과 C 해제는 그대로다.
- **모든 플레이어가 보스 투사체를 본다.** 투사체는 기존 발사/명중/끝 이벤트와 같은 방식으로 복제된다. 발사자 칸 0은 보스를 뜻하고, 클라이언트는 보스의 투사체 모양(속도, 수명, 반지름)과 색으로 규칙대로 그린다. 명중 이벤트는 표적이 생존자인지 알리는 표시 비트를 하나 더 갖는다(이벤트 크기는 그대로).
- **개발 인자.** 보스가 쏘게 하는 `-bsBossFire`와 보스 투사체 피해를 바꾸는 `-bsBossShotDamage`를 넣는다. 기존 `-bsFire`는 생존자 전용으로 남겨, 이전 시험이 달라지지 않게 한다.
- **화면.** 보스 화면의 키 안내가 "왼쪽 클릭 발사, Space 소환, 오른쪽 클릭 목표 지정, C 지정 해제"로 바뀐다. 생존자에게는 새 UI가 없고 투사체와 피해만 보인다.
- 범위 밖(다음 change): 보스 스킬, 보스 종류 2종, 자동 소환 장치, 몹 종류 다양화, 캐릭터별 스킬 트리, 보스 전용 에셋, 점수, 유도 투사체. 보스 투사체는 단일 직선 발사이고 관통이나 다발 발사는 없다.

## Capabilities

### New Capabilities
- `boss-projectiles`: 보스의 조준과 발사 입력, 서버 판정(쿨타임, 발사 조건), 보스 투사체의 비행과 생존자 명중, 복제와 표시, 보스 화면의 키 안내.
- `boss-enrage`: 보스 체력 비율에 따른 발사 간격과 투사체 피해의 강화 규칙.

### Modified Capabilities
- `aimed-attack`: "투사체는 몹과 보스만 해친다"가 생존자 투사체에 한정된 규칙이 된다(보스의 투사체는 `boss-projectiles`가 정한다).
- `attack-replication`: 명중 이벤트가 표적이 생존자인 경우를 구분하고, 보스 발사까지 합친 전투 트래픽 예산을 지킨다.
- `survivor-health`: 투사체도 생존자 피해의 한 원천이고 같은 보호 시간 규칙을 따른다.

## Impact

- 코드: `BossCatalog`/`BossDef`(투사체 값, 강화 값), 새 순수 C# `Combat/BossAttack`(강화 계산과 보스 공격 정의), `ProjectileSim`(적대 투사체: 생존자 명중), `ProjectileSpec`, `CombatEvent`/`CombatCodec`(생존자 표적 비트), `AttackSim` 재사용(보스를 사수로 등록), `CombatServer`(보스 사수 등록과 몸 정보, 강화 적용, 발사 조건, 피해 처리), `PlayerCombat`(보스 입력과 조준), `PlayerSummon`(소환 입력에서 왼쪽 클릭 제거), `ProjectileReplay`/`CombatView`/`CombatClient`(보스 칸의 모양과 색, 생존자 명중 효과), `SummonHud`(키 안내), `DevArgs`가 바뀐다.
- 네트워크: 새 메시지는 없다. 기존 전투 이벤트 스트림을 쓰고, 명중 이벤트의 flags 바이트에 비트 하나를 더한다. 보스의 조준과 발사 입력은 생존자와 같은 `SetAimRpc`를 쓴다. 보스 발사가 더해지므로 전투 트래픽(10 KB/s 이하)과 몹 트래픽(50 KB/s 이하)을 Relay로 다시 잰다.
- 동작 변화: 보스 판에서 보스가 처음으로 투사체로 피해를 준다. 소환의 왼쪽 클릭이 사라지고 Space만 남는다(**BREAKING** 조작: 소환 시험 스크립트는 자동 소환 인자라 영향이 없지만, 손으로 하는 시험은 키가 바뀐다).
- 테스트: 강화 계산, 적대 투사체 명중 규칙, 코덱 비트, 보호 시간은 순수 C#이라 EditMode로, 보스 + 생존자 여러 프로세스(보스 발사, 생존자 피해, 강화, 이벤트 일치, 이전 회귀)와 실제 Relay로 검증한다.
- 저작권: 이 단계도 이름과 임시 색, 도형만 쓴다.
- 이후 change: 보스 스킬, 보스 종류 2종, 자동 소환 장치.
