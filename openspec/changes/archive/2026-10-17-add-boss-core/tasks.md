## 3. 승패 규칙과 방 상태 (match-outcome, room-lobby)

- [x] 4.1 `BossCatalog`를 서버에 연결한다: 판이 시작될 때 보스 플레이어의 `BossSim`을 만들어(체력은 정의, 개발 인자 `-bsBossHealth`로 바꿈) 보스 위치를 매 틱 넘기고, `ProjectileSim`, `SkillContext`, `SurvivorSim`에 보스를 넘기며, 보스의 `PlayerCombat` 체력 값을 채운다. 보스 이동 속도가 보스 정의를 따르고 쓰러지면 보스가 움직이지 않으며, 에디터 `eval`로 보스가 맞아 체력이 줄고 생존자가 보스와 닿아 다치는 것을 확인한다

- [x] 4.3 정지 스위치를 둔다: `Phase`가 진행이 아니면 `MobServer`, `CombatServer`, `GrowthServer`, `PlayerAvatar` 이동의 서버 갱신을 멈추고(마지막 값을 한 번 쓰고 정지) 소유자 입력(이동, 조준, 발사, 스킬, 선택)도 서버로 보내지 않게 한다. 에디터 `eval`로 결과 상태에서 몹 위치 합계, 투사체 수, 남은 시간이 변하지 않고 입력이 무시되는 것, 호스트가 대기방으로 돌아가면 모두 정리되는 것과 둘째 판이 처음과 같은 것을 확인한다
