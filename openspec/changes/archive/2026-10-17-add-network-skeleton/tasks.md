## 2. 세션 연결 (multiplayer-session)

- [x] 2.1 NetworkManager와 Unity Transport를 씬에 설정하고, 호스트로 시작 후 로컬 클라이언트가 접속되는 것을 Multiplayer Play Mode로 확인한다
- [x] 2.2 호스트가 Relay 할당을 받아 접속 코드를 반환하는 흐름을 구현하고, 실패 시 오류가 표시되는 것(네트워크 차단 상태)을 확인한다
- [x] 2.3 클라이언트가 접속 코드로 Relay에 참가하는 흐름을 구현하고, 잘못된 코드가 오류 메시지를 내고 방이 변하지 않는 것을 확인한다
- [x] 2.4 접속 승인 단계에서 정원(5명) 초과를 거절하고, 6번째 접속 시도가 거절되며 기존 접속자가 영향받지 않는 것을 확인한다
- [x] 2.5 서버가 역할 슬롯 테이블(보스/생존자 1~4)을 `NetworkList`로 관리하게 하고, 호스트가 보스/생존자를 선택하는 두 시나리오에서 역할이 spec대로 배정되는지 확인한다
- [x] 2.6 클라이언트 이탈 시 슬롯과 캐릭터가 해제되고, 호스트 이탈 시 클라이언트가 접속 화면으로 돌아가는 것을 확인한다

## 3. 캐릭터와 이동 동기화 (player-movement-sync)

- [x] 3.1 임시 캐릭터 프리팹(색 구분 사각형 스프라이트, NetworkObject)을 만들고, 접속 시 역할별 스폰 위치에 생성되어 모든 클라이언트에 보이는지 확인한다
- [x] 3.2 Input System 이동 입력을 서버로 보내 서버가 위치를 계산하는 구조를 구현하고, 모든 클라이언트에서 같은 위치로 보이는지 확인한다
- [x] 3.3 소유자 화면의 로컬 반응과 서버 위치 보정(임계값을 인스펙터에 노출)을 구현하고, 입력 즉시 이동이 시작되며 임계값 초과 시 서버 위치로 보정되는 것을 확인한다
- [x] 3.4 조작된 클라이언트 위치 주장이 서버 위치로 되돌려지는 것을 테스트 스크립트나 수동 조작으로 확인한다
- [x] 3.5 아레나 경계(상수 32 x 20 유닛)를 서버에서 적용하고, 가장자리로 계속 이동해도 캐릭터가 밖으로 나가지 않는 것을 확인한다
