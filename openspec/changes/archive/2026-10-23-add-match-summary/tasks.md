## 1. 쓰러짐과 부활 횟수 (match-outcome)

- [x] 1.1 `SurvivorSim`의 `State`에 `Falls`와 `Revives`를 더하고, `ApplyDamage`가 체력을 0으로 만들 때, 개발용 `Kill`이 서 있던 생존자를 쓰러뜨릴 때 쓰러짐을, 부활 게이지가 차서 일어날 때 부활을 센다. `Register`와 `Clear`에서 0으로 되돌리고, 모르는 생존자는 `FallsOf`/`RevivesOf`가 0을 준다. ## 5. 통합 확인과 문서

- [x] 5.1 (통합) 직접 IP 다중 프로세스로 판이 끝나는 세 방식(보스 처치, 생존자 전멸, 시간 종료)을 돌려, 각각 서버와 모든 클라이언트가 같은 요약을 받고(로그 비교), 한 판에서 쓰러짐과 부활이 실제 일어난 값과 같은지(서버 로그의 쓰러짐/부활 줄 수와 요약의 합) 보고, 호스트가 대기방으로 돌아간 뒤 둘째 판의 요약이 첫 판의 값을 이어받지 않는 것과, 보스 없는 연습 판에는 요약이 없는 것을 확인한다. 기존 시나리오(소환·명령, 장치, 전투, 성장, 보스 승패)가 이전과 같은 모양인지 본다
