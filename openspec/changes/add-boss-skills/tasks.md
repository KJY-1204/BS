# Tasks

## 1. 스킬 규칙 (boss-skills)

- [x] 1.1 순수 C# `BossSkills`(두 스킬의 이름, 발수 12, 기본 피해 10과 30, 쿨타임 10초와 8초, 충격파 반지름 4.0, 예고 시간 0.8초, 예고 번호 200/201)와 `BossSkillSim`(슬롯별 쿨타임과 예고 중인 스킬, `Step`은 판이 돌 때만 쿨타임과 예고를 줄이고 끝난 스킬을 실행, `Reset`은 둘 다 준비와 예고 취소, `TryUse` 결과 `Used/Cooldown/Unavailable/Ignored/UnknownSlot`, 확인 순서는 보스 아님 -> 판/보스 상태 -> 슬롯 -> 쿨타임, 쓰는 순간의 위치와 조준과 강화된 피해를 저장)를 만든다. EditMode 테스트로 쿨타임이 쓰는 순간 시작하고 정확히 그 시간 뒤 준비되는 것(예고와 무관), 두 슬롯이 독립인 것, 판이 안 도는 동안 줄지 않는 것, 새 판이 둘 다 준비로 시작하는 것, 보스 아님/보스 쓰러짐/판 종료/모르는 슬롯 거절이 쿨타임을 시작하지 않는 것, 예고 시간이 지나야 실행되는 것, 예고 중 판 종료나 보스 쓰러짐으로 취소되는 것, 예고 이벤트가 쓰는 순간 하나 나오는 것을 확인한다
- [x] 1.2 탄막: 예고가 끝나면 쓴 순간의 위치에서 12발을 고르게(각도 간격 65536/12) 퍼뜨려 첫 발을 조준 방향으로 쏘는 적대 투사체로 만들고(소유자는 보스, `BossAttack.Shape`, 강화된 피해), 상한에 걸리면 나간 만큼만 나간다. EditMode 테스트로 발수와 각도 간격과 첫 발 방향, 시작 위치, 피해, 강화(체력 가득/낮음의 피해와 쿨타임), 상한으로 일부만 나가는 것과 하나도 못 나가는 것, 보스가 예고 중에 움직여도 쓴 순간의 자리에서 나가는 것, 맞은 생존자의 체력, 보호 시간 중 통과, 몹과 보스 통과를 확인한다
- [x] 1.3 충격파: 예고가 끝나면 쓴 순간의 위치 기준 반지름 안의 살아 있는 생존자에게 `ApplyBlast`로 강화된 피해를 주고(밀어내기 없음, 몹과 보스는 다치지 않음) `Explosion` 이벤트(위치와 반지름)를 이벤트 목록에 더한다. EditMode 테스트로 예고 중에 범위를 벗어난 생존자는 피해가 없는 것, 범위 안과 밖, 각 생존자 한 번, 보호 시간 중과 쓰러진 생존자 무피해, 위치가 변하지 않는 것, 이벤트의 위치와 반지름, 강화된 피해와 쿨타임, 이후 보호 시간 시작을 확인한다

## 2. 서버와 입력 (boss-skills, boss-combat)

- [x] 2.1 `CombatServer`에 보스 스킬을 연결한다: `BossSkillSim`을 갖고 `FixedUpdate`에서 `Step`(판이 돌 때만), `RegisterBoss`와 `ResetAll`에서 `Reset`, `OnBossSkillRequest(clientId, slot)`가 보스 소유자인지 확인해 `TryUse`(보스 위치, 마지막 조준 각도, 체력 비율)를 부르고, 충격파 이벤트가 같은 틱 이벤트 발행에 실리게 한다(`blastEvents`). 쿨타임을 보스의 `PlayerSummon`에 쓴다. 서버 로그(`[BS] boss skill: slot=... result=... damage=... cooldown=...`)와 5초 전투 통계에 스킬 사용 수와 충격파 적중 수를 더한다. 에디터 `eval`로 사용, 쿨타임, 거절, 정지, 초기화를 확인한다
- [x] 2.2 `PlayerSummon`: 보스 소유자의 Q/E 키(지난 프레임 상태와 비교, 최소 간격 0.1초)를 읽어 `SkillRpc(byte slot)`로 서버에 보내고(호스트가 보스면 직접 호출), 보스 소유자만 읽는 쿨타임 `NetworkVariable<byte>` 둘(1/10초 단위)과 읽기 속성(`SkillCooldown(slot)`)을 더한다. 생존자의 `PlayerSummon`은 입력을 읽지 않고 값을 받지 않는다. 개발 인자 `-bsAutoBossSkill <q|e|qe> <초>`(결과 상태에서도 계속 보냄)와 `-bsBossSkillDamage <n>`을 `DevArgs`에 더하고 서버가 쓰게 한다. 에디터에서 Q/E 입력이 서버에 도착하는 것과 비보스 요청이 무시되는 것을 확인한다
