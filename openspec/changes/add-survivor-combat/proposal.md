# Proposal

## Why

몹은 이제 움직이고 동기화되지만, 생존자가 몹을 쓰러뜨리거나 몹에게 피해를 입을 방법이 없어 게임이 아직 게임이 아니다. 이 change는 생존자 전투의 최소 핵심을 만든다: 직접 조준해서 쏘는 기본 공격, 체력과 피해, 몹 처치, 생존자 사망과 동료 부활. 공격 한 발이 네트워크에서 어떻게 보이는지(서버는 판정, 클라이언트는 이벤트로 재생)를 여기서 확정해야 이후 캐릭터별 공격과 스킬이 같은 방식 위에 쌓인다. Change 2에서 만든 몹 제거 이벤트, 지목 훅, 생존자 `Alive` 자리, 메시지 전송 기반을 그대로 이어서 쓴다.

## What Changes

- **직접 조준 공격**: 소유자가 마우스(자기 캐릭터 기준 월드 방향) 또는 게임패드 오른쪽 스틱으로 조준하고, 발사 버튼(마우스 왼쪽, 오른쪽 트리거)을 누르고 있는 동안 쿨타임마다 조준 방향으로 발사한다. 조준과 발사 상태는 바뀔 때만 서버로 보내며 전송 빈도에 상한을 둔다. 쿨타임과 발사는 서버가 판정한다.
- **투사체**: 이번에는 캐릭터 구분 없는 직선 투사체 한 종류. 서버가 순수 데이터로 시뮬레이션하고(위치, 속도, 수명), 몹 격자를 재사용해 충돌을 판정한다. 첫 몹에 맞으면 피해를 주고 사라진다. 보스와 다른 생존자는 통과한다.
- **복제**: 서버는 발사 이벤트와 명중/소멸 이벤트만 신뢰 전송하고, 클라이언트는 같은 규칙으로 직선 비행을 재생한다. 투사체 위치 스냅샷은 보내지 않는다. 이벤트에 정밀한 서버 시각을 실어 몹 표시 시각과 맞춘다.
- **몹 체력과 처치**: 몹에 체력이 생기고 0이 되면 제거된다(기존 제거 이벤트). 클라이언트에서는 투사체가 도착하는 표시 시각에 몹이 사라지도록 제거를 서버 시각에 맞춰 적용한다. 맞은 몹은 잠깐 체력바를 보여 준다.
- **생존자 체력, 피해, 사망**: 생존자 체력을 모두에게 복제한다. 몹이 닿으면 접촉 피해(무적 시간 포함)를 입고, 0이 되면 사망한다. 죽은 생존자는 이동과 공격이 불가능하고 몹의 타겟에서 제외된다(`SurvivorInfo.Alive`를 실제 값으로 연결).
- **부활**: 살아 있는 생존자가 죽은 동료 근처에서 움직이지 않고 있으면 부활 게이지가 차고, 움직이거나 범위를 벗어나면 초기화된다. 가득 차면 일부 체력으로 부활하고 짧은 무적 시간을 갖는다.
- **화면**: 로컬 생존자의 체력 표시, 캐릭터 위 체력바, 조준 표시, 죽은 생존자 표시와 부활 게이지를 최소한으로 보여 준다.
- **전 단계 변경**: 몹/전투 메시지의 시간 기준을 서버 시각(밀리초)으로 통일한다. 기존 몹 스냅샷과 이벤트의 틱 번호를 이 값으로 바꾼다.
- 범위 밖: 경험치, 레벨업, 스킬트리, 마나, 키 입력 스킬, 캐릭터별 고유 공격(레이무, 마리사, 사쿠야, 사나에), 보스 피해와 승패, 전멸 시 종료, 소환 명령, 에셋, 점수. 다음은 Change 4(성장과 캐릭터)와 Change 5(보스 역할)다.

## Capabilities

### New Capabilities
- `survivor-health`: 생존자 체력, 피해와 무적 시간, 사망, 죽은 생존자의 제약, 체력 표시.
- `aimed-attack`: 조준과 발사 입력, 서버의 쿨타임/발사 판정, 직선 투사체의 비행과 명중, 대상 제한.
- `attack-replication`: 발사와 명중/소멸 이벤트의 복제, 클라이언트의 투사체 재생과 표시 시각 정렬, 맞은 몹의 체력바, 전투 트래픽 예산.
- `survivor-revival`: 부활 게이지 규칙, 초기화 조건, 부활 결과와 표시.

### Modified Capabilities
- `mob-simulation`: 몹에 체력과 처치, 생존자에 대한 접촉 피해 요구사항을 추가한다(기존 요구사항 문구는 바꾸지 않음).
- `mob-replication`: 몹 제거를 서버 시각에 맞춰 표시하는 요구사항을 추가한다(기존 요구사항 문구는 바꾸지 않음).

## Impact

- 코드: `Assets/Scripts/Combat/`(투사체 시뮬레이션, 부활 규칙, 이벤트 부호화, 클라이언트 재생, 화면)를 새로 추가한다. `MobSim`에 체력, 피해 적용, 선분 충돌 조회, 접촉 판정이 추가되고, `MobCodec`/`MobServer`/`MobClient`/`MobInterpolator`는 서버 시각 통일과 시각 지정 제거에 맞게 바뀐다. `PlayerAvatar`/`PlayerRegistry`/`RoleTable`/프리팹/씬 설정은 체력, 입력, 연결 지점이 추가된다.
- 네트워크: 새 커스텀 메시지(전투 이벤트)를 추가한다. 새 패키지는 없다.
- 입력: 마우스 위치와 게임패드 오른쪽 스틱/트리거를 Input System으로 읽는다.
- 테스트: 투사체, 피해, 부활 규칙은 순수 C#이라 EditMode로, 네트워크 동작은 개발 빌드 여러 프로세스 로그로 검증한다. 기존 몹 테스트는 시간 기준 변경에 맞게 고친다.
- 이후 change: 캐릭터별 공격(Change 4)이 같은 이벤트 방식 위에 모양만 늘려 간다. 보스 피해와 승패(Change 5)가 `Alive`와 체력 규칙을 이어서 쓴다.
