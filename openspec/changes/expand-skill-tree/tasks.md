- [x] 1.1 `SkillCatalog`에 번호 21~28의 전용 패시브 여덟 개(design 표: 수호의 부적, 봉마진, 별빛 탄환, 마력 순환, 정밀 투척, 우아한 절약, 공덕, 신령의 가호)와 새 `PassiveEffectKind` 셋(`DamageTaken`, `BasicDamage`, `ExperienceGain`), 랭크당 값 상수를 정의한다(`IsActive = false`, 최대 랭크 3, 설명 문구, 선행 조건: 21/23/25/27은 자기 E 스킬 1랭크, 22/24/26/28은 자기 Q 스킬 3랭크). EditMode 테스트로 소유 캐릭터, 효과 종류, 선행, 최대 랭크, 번호 유일성을 확인하고, 전용 패시브가 "정확히 둘"이라고 가정한 기존 시험을 "정확히 넷"으로 고친다
- [x] 1.2 랭크 포장을 `ulong` 둘로 넓힌다: `MaxSkillId`를 42로, `Pack`/`Unpack`을 번호 1~21(낮은 값)과 22~42(높은 값)로 나눠 다루게 바꾸고 `PlayerGrowth`에 소유자에게만 복제되는 `ranksPackedHigh`를 더하고 `GrowthServer`가 두 값을 쓴다. EditMode 테스트로 번호 1~42의 라운드트립, 번호 21과 22(경계)가 서로 영향 없는 것, 기존 호출 시험이 새 시그니처에서 통과하는 것을 확인한다
- [x] 1.3 선택지 규칙: 새 패시브가 자기 캐릭터에게만, 선행 랭크 뒤에만 나오는지 EditMode 테스트로 확인한다(E 1랭크 전에는 2단계 불가, Q 3랭크 전에는 3단계 불가, Q 2랭크에서는 3단계 불가, 다른 캐릭터에게 안 나옴, 최대 랭크 뒤 안 나옴). 한 캐릭터가 배울 수 있는 랭크가 38이고 레벨 1에서 상한까지의 선택 횟수보다 큰 것, 레벨 20까지 올려도 선택이 비지 않는 것을 확인한다. `LevelingSim`의 선택지 로직은 바뀌지 않아야 한다(경험치 계산은 2.3에서 바뀐다)

## 2. 새 효과 종류 (character-passives, survivor-health, survivor-leveling)

- [x] 2.1 받는 피해 감소: `StatCalc`/`SurvivorStats`에 받는 피해 배율(`1 - min(0.6, 합)`)을 더하고, `GrowthServer.ApplyStats`가 `SurvivorSim`에 생존자별로 넘기고, `SurvivorSim.ApplyDamage`가 보호/쓰러짐 검사 뒤 `max(1, round(피해 x 배율))`을 적용한다. EditMode 테스트로 랭크별 감소, 총합 상한, 피해 1이 1로 남는 것, 보호 중이거나 쓰러진 생존자는 여전히 피해를 안 받는 것, 폭발과 접촉이 같은 길을 지나는 것, 패시브 없는 생존자는 전액을 받는 것, 부활 뒤에도 배율이 유지되는 것을 확인한다
- [x] 2.2 기본 공격 피해 증가: `StatCalc`가 `ProjectileDamage`를 `round((기본 + 레벨 + 힘) x (1 + 합))`으로 계산한다. EditMode 테스트로 랭크별 값, 레벨/힘과 합쳐진 값, 스킬 피해는 안 바뀌는 것, 패시브 없는 캐릭터는 이전 값과 같은 것을 확인한다
- [x] 2.3 경험치 획득 증가: `LevelingSim.AwardKill`이 받는 사람마다 `max(기준량, round(기준량 x (1 + 합)))`을 준다. EditMode 테스트로 패시브 있는 사람과 없는 사람이 같은 처치에서 다른 양을 받는 것, 반올림, 기준량 아래로 안 내려가는 것, 상한에서 무시되는 것, 거리 규칙이 그대로인 것을 확인한다
