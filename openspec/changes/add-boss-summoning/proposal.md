# Proposal

## Why

보스는 이제 체력과 접촉 피해와 제한 시간을 갖췄지만, 보스 플레이어가 할 수 있는 일은 걸어 다니며 부딪히는 것뿐이고 몹은 여전히 서버가 알아서 뿌린다. 이 게임의 비대칭 4v1은 "보스가 몹을 소환해 생존자를 몰아붙인다"에서 재미가 나오므로, 보스에게 몹을 부르는 힘과 그 몹을 어디로 보낼지 정하는 힘을 준다. 탐색에서 정한 대로 자동 스폰은 약한 바닥으로 낮춰 두고(0은 아님) 보스의 소환이 주력이 되게 한다.

## What Changes

- **보스가 몹을 소환한다.** 보스 플레이어가 소환 키를 누르면 서버가 보스 주변에 몹 한 무리를 만든다. 소환은 보스 전용 자원("소환 기운")을 쓴다. 자원은 시간이 지나면 차오르고 상한이 있으며, 부족하거나 몹이 하드 상한에 닿았거나 보스가 쓰러졌거나 판이 진행 중이 아니면 소환은 거절된다(자원은 소모되지 않는다).
- **소환 몹은 구분된다.** 소환된 몹은 자동 스폰 몹과 다른 종류 표시(색)를 갖는다. 새 네트워크 형식은 없다(몹 스폰 이벤트가 이미 실어 보내는 종류 값을 쓴다).
- **보스가 명령으로 소환 몹의 목표를 정한다.** 보스는 생존자 하나를 목표로 지정하거나(오른쪽 클릭), 아레나의 한 지점을 지정하거나(오른쪽 클릭), 지정을 해제한다. 명령은 살아 있는 소환 몹 전부와 이후에 소환하는 몹에게 적용된다. 이렇게 처음으로 기존 목표 지정 훅을 쓴다. 지점 지정은 "그 지점까지 간 뒤 다시 가까운 생존자를 쫓는다". 명령이 없거나 지정한 생존자가 쓰러졌거나 나가면 지금처럼 가장 가까운 생존자를 쫓는다. 자동 스폰 몹은 명령을 받지 않는다.
- **자동 스폰은 약해진다.** 보스가 있는 판에서는 자동 스폰의 속도와 목표 수가 지금보다 낮아진다(0이 아님). 보스가 없는 연습 판은 지금 값 그대로다. 자동 스폰의 목표 수는 자동 스폰 몹만 센다. 소환 몹은 하드 상한 100을 자동 몹과 나눠 쓴다.
- **화면.** 보스 플레이어는 소환 기운 막대, 소환 키 안내, 현재 명령(목표 생존자 또는 지점 표시)을 본다. 소환 기운과 명령은 보스에게만 보내고 생존자에게는 보내지 않는다(생존자는 새로 생긴 몹이 보일 뿐이다).
- **개발 인자.** 보스가 일정 간격으로 소환하게 하는 `-bsAutoSummon`, 명령을 자동으로 내리는 `-bsAutoOrder`, 소환 기운을 바꾸는 `-bsSummonEnergy`를 넣어 여러 프로세스 시험을 자동화한다.
- 범위 밖(다음 change): 자동 소환 장치, 보스 종류 2종과 보스 스킬, 체력이 줄수록 강해지는 보스, 보스 전용 에셋, 점수, 캐릭터별 스킬 트리, 몹 종류 다양화(소환 몹은 지금 몹과 능력이 같고 색만 다르다).

## Capabilities

### New Capabilities
- `boss-summoning`: 소환 입력과 서버 판정, 소환 기운(충전, 소모, 상한), 소환 위치와 거절 규칙, 소환 몹 표시, 보스 전용 정보 복제와 보스 화면.
- `boss-orders`: 소환 몹에 대한 보스의 명령(생존자 지정, 지점 지정, 해제), 적용 대상, 해제 조건, 명령 표시.

### Modified Capabilities
- `mob-simulation`: 자동 스폰이 보스가 있는 판에서 더 느리고 목표 수가 작으며 자동 스폰 몹만 세고, 몹에 출처(자동 또는 소환)가 있으며, 지점 지정은 도착하면 풀린다.
- `boss-combat`: 보스 화면에 소환 기운과 명령이 더해진다.

## Impact

- 코드: `MobConfig`(약해진 자동 스폰 값, 소환 값), `MobSim`(몹 출처, 자동 스폰 계산, 소환 API, 지점 도착 해제, 명령 일괄 적용), 새 순수 C# `Combat/SummonSim`(소환 기운, 소환 판정, 위치 고르기, 명령 상태), `MobServer`/`CombatServer`(서버 연결, 정지 스위치 재사용), `RoleTable` 또는 새 `Player/PlayerSummon`(보스 전용 복제 값, 소환/명령 RPC), `MobView`(소환 몹 색 확인), 새 `UI/SummonHud`(소환 기운, 명령 표시)와 `NetworkSceneSetup`, `DevArgs`가 바뀐다.
- 네트워크: 몹 스냅샷과 이벤트 형식은 그대로다. 새 것은 보스 소유자만 받는 소환 기운/명령 복제 값과, 보스가 서버에 보내는 소환/명령 RPC뿐이다. 몹이 늘어나므로 몹 트래픽(50 KB/s 이하)과 전투 트래픽(10 KB/s 이하)을 Relay로 다시 잰다.
- 동작 변화: 보스가 있는 판에서 자동 스폰이 줄어든다(**BREAKING** 개발 시험: 보스를 넣고 `-bsMobTarget`으로 몹 수를 맞추던 시험은 소환 몹이 없으면 몹이 적어진다. 연습 판은 이전과 같다).
- 테스트: 소환 기운, 소환 위치와 거절, 명령 규칙은 순수 C#이라 EditMode로, 보스 + 생존자 여러 프로세스(소환, 명령, 몹 위치 일치, 전투 이벤트 일치, 이전 회귀)와 실제 Relay로 검증한다.
- 저작권: 이 단계도 이름과 임시 색, 도형만 쓴다.
- 이후 change: 자동 소환 장치, 보스 종류와 스킬, 체력 비례 강화.
