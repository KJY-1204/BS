## 2. 시뮬레이션: 관통과 다발 (aimed-attack, character-attacks, mob-simulation)

- [x] 2.3 `AttackSim`이 생존자 등록 때 캐릭터의 `AttackDef`로 한 번에 발수만큼 균등 분산해 쏘고(발 1이면 정확히 조준), 간격을 `간격 x 쿨타임 배율`로 하고 피해를 `max(1, round(피해 x 배율))`로 발사 때 투사체에 저장하며, 상한 때문에 일부만 들어가면 들어가는 만큼 쏘고 한 발이라도 나갔으면 쿨타임을 시작하게 한다. 캐릭터별 초당 공격 횟수와 발수, 피해 배율 반올림과 최소 1, 쿨타임 감소가 발수를 바꾸지 않는 것, 상한 도달, 기존 테스트가 통과하는 것을 EditMode 테스트로 확인한다
